# Git Workflow

Este proyecto usa un flujo simple para talleres y ejercicios.

## Ramas recomendadas
- main: rama estable
- feature/nombre: nuevas prácticas o ejercicios
- fix/nombre: correcciones

## Flujo sugerido
1. Crear rama desde main.
2. Trabajar en cambios pequeños.
3. Validar con `cargo check`.
4. Hacer commit con mensajes claros.
5. Abrir PR y revisar antes de merge.

## Comandos básicos
```bash
cargo check
cargo run
cargo fmt
```
